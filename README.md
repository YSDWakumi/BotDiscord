# BotDiscord

บอท Discord สำหรับจัดการ Ticket และแสดงสถิติเซิร์ฟเวอร์แบบ ServerStats

## ฟีเจอร์หลัก

- ระบบ Ticket แยกประเภท พร้อมสิทธิ์การเข้าถึงห้อง
- Claim, เปลี่ยนสถานะ, Priority, เพิ่ม/ลบสมาชิก และปิด Ticket
- สร้าง Transcript และส่งแบบประเมินความพึงพอใจผ่าน DM
- Dashboard แสดงสมาชิก บอท คนออนไลน์ คนใน Voice Ticket ที่ปิดแล้ว และ Admin
- สร้างหมวดหมู่และห้องสถิติอัตโนมัติ พร้อมรีเซ็ตห้องสถิติเมื่อบอทเริ่มทำงาน
- โหลดการตั้งค่าจากไฟล์ `.env`

## การติดตั้ง

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

สร้างไฟล์ `.env` จาก `.env.example` แล้วใส่ Token และ ID ที่จำเป็น จากนั้นรัน:

```powershell
python discord_bot.py
```

> ห้ามเผยแพร่ไฟล์ `.env` หรือ Bot Token

## คำสั่งสำคัญ

| คำสั่ง | รายละเอียด |
| --- | --- |
| `/dashboard show` | สร้าง/อัปเดต Dashboard ในห้อง `dashboard` |
| `/ticket ...` | จัดการ Ticket |
| `>version` | แสดงข้อมูลเวอร์ชันล่าสุด |
| `>history` | แสดงประวัติเวอร์ชันทั้งหมด |
